# homebrew-tap

Homebrew casks for [jonymusky](https://me.jonymusky.com)'s apps.

```bash
brew install --cask jonymusky/tap/indicators
```

| Cask | App |
| --- | --- |
| `indicators` | [Indicators](https://indicators.jonymusky.com) — AI usage and cost in the macOS menu bar |

Casks are updated from the app repositories on each release (`scripts/update-cask.sh` in each repo).
